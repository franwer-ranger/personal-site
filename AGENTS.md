## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Writing

Any copy work — rewriting strings, drafting new text, i18n (ES/EN), project/experience content, UI labels, or marketing-ish lines — must use the skills in `.agents/skills/` before writing or editing:

1. **`voz-fran`** — write in Fran's voice (direct, concrete, peninsular Spanish; professional level for portfolio).
2. **`no-ai-slop-es`** (Spanish) / **`no-ai-slop`** (English) — strip AI patterns (binary contrasts, throat-clearing, colon reveals, corporate filler, fake profundity). Run the skill's `eval.md` checklist before shipping the text.

Do not invent a “polished portfolio” tone that skips these skills. Read the skill files first; apply them; then edit. For bilingual changes, keep meaning aligned across locales without calquing.
